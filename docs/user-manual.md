# 用户使用手册

## 1. 系统简介

烟草采销存协同管理平台用于管理烟草业务中的基础资料、采购订单、销售订单、库存流转、统计报表、合规追溯、异常审核和系统权限。系统采用浏览器访问方式，用户登录后可根据自身角色权限使用不同功能。

访问地址：

```text
http://服务器IP:8080
```

如在本机运行，可访问：

```text
http://localhost:8080
```

## 2. 默认账号

系统内置以下演示账号：

| 角色 | 账号 | 密码 | 主要权限 |
| --- | --- | --- | --- |
| 超级管理员 | admin | 123456 | 全部功能 |
| 普通管理员 | manager | 123456 | 系统管理、基础资料、报表管理 |
| 采购专员 | buyer | 123456 | 采购订单、采购入库、部分报表和追溯 |
| 销售专员 | seller | 123456 | 销售订单、销售出库、销售公告、回款、部分报表和追溯 |

说明：系统菜单会根据账号权限自动显示。不同账号登录后看到的菜单可能不同。

### 2.1 答辩演示角色清单

答辩演示时重点使用以下角色账号：

```text
admin / buyer / seller / keeper
```

其中 `admin` 负责全局管理和最终审核，`buyer` 负责采购业务，`seller` 负责销售业务，`keeper` 负责库存入库、出库、调拨和盘点。

### 2.2 超级管理员：admin

超级管理员拥有系统最高权限，可管理平台基础配置、账号角色、业务审核和运行监控。

主要权限：

- 权限管理：负责角色分配、权限配置和菜单管控。
- 用户管理：可新增、编辑、停用、删除用户账号，并可重置用户密码。
- 基础信息管理：统一维护烟草品类、供应商、客户、仓库、商品价格和库存预警阈值。
- 系统日志管理：查看全平台登录日志和操作日志。
- 系统配置：维护库存预警阈值、消息通知等系统参数。
- 审核权限：拥有采购、销售、异常单据等所有关键业务的审核和终审权限。

答辩演示时，超级管理员适合用于展示完整菜单、权限控制、基础资料维护、订单审核、日志审计和异常处理。

### 2.3 采购专员：buyer

采购专员的核心职责是联系供货商、采购烟草商品，并发起采购入库流程。采购专员通常负责提交入库申请，库管人员负责执行实际入库。

采购管理功能：

- 采购需求提报。
- 采购订单创建、提交管理员审核、修改、取消。
- 采购订单 Excel 导入、导出。
- 采购订单跟踪，查看订单审核、到货和入库状态。
- 采购数据分析，查看采购结构和供应商占比。

典型流程：

```text
采购专员创建采购订单 -> 提交管理员审核 -> 审核通过 -> 到货登记 -> 库管执行入库
```

### 2.4 销售专员：seller

销售专员的核心职责是联系客户、销售烟草商品，并发起销售出库流程。销售专员通常负责提交出库申请，库管人员负责执行实际出库。

销售管理功能：

- 销售信息发布。
- 销售订单创建、提交管理员审核、修改、取消。
- 销售订单 Excel 导入、导出。
- 客户回款状态查看和回款登记。
- 销售业绩统计，查看销售趋势、达成率和区域表现。

典型流程：

```text
销售专员创建销售订单 -> 提交管理员审核 -> 审核通过 -> 库管执行出库 -> 销售专员登记回款
```

### 2.5 仓库管理员：keeper

仓库管理员的核心职责是维护库存准确性，处理采购入库、销售出库、库存调拨和库存盘点。

库存管理功能：

- 库存实时维护，支持库存数据 Excel 导入、导出。
- 执行采购入库、销售出库和库存调拨操作。
- 执行库存盘点，并上报库存盈亏差异。
- 查询库存台账和库存流水，追踪每次库存变动。

典型流程：

```text
接收入库或出库申请 -> 选择仓库和商品 -> 执行入库、出库、调拨或盘点 -> 生成库存流水
```

### 2.6 业务流程条线

采购业务闭环：

```text
超级管理员维护基础信息和权限 -> 采购专员提需求并下采购订单 -> 超级管理员审核 -> 库管入库 -> 全角色查看报表和追溯
```

销售业务闭环：

```text
超级管理员维护基础信息和权限 -> 销售专员发布信息并下销售订单 -> 超级管理员审核 -> 库管出库 -> 全角色查看报表和追溯
```

库存核心联动：

```text
采购入库 -> 库存增加
销售出库 -> 库存减少
库存低于阈值 -> 自动预警 -> 通知超级管理员和采购专员补货
```

合规与监控闭环：

```text
所有操作生成日志 -> 超级管理员审计日志和关键单据 -> 系统支持全流程追溯 -> 异常单据由超级管理员终审监控
```

## 3. 登录与退出

### 3.1 登录系统

1. 打开浏览器，访问系统地址。
2. 在登录页输入账号和密码。
3. 输入页面显示的验证码。
4. 可勾选“记住我”。
5. 点击“登录系统”。

登录成功后进入“驾驶舱”页面。

### 3.2 忘记密码

1. 在登录页点击“忘记密码？”。
2. 输入需要找回的账号。
3. 输入验证码。
4. 点击“获取重置凭证”。
5. 系统跳转到重置密码页面后，按页面提示设置新密码。

### 3.3 退出登录

1. 点击页面右上角用户头像或用户名区域。
2. 选择“退出登录”。
3. 在确认框中点击确认。

## 4. 页面布局说明

登录后主界面由以下区域组成：

| 区域 | 说明 |
| --- | --- |
| 左侧菜单 | 按业务模块展示可访问功能 |
| 顶部栏 | 显示当前页面标题、暗黑模式开关、消息提醒、用户信息 |
| 主工作区 | 展示当前菜单对应的业务页面 |
| 消息提醒 | 展示库存预警、业务通知等站内消息 |

常用操作：

- 点击左侧菜单切换功能页面。
- 点击顶部折叠按钮可收起或展开菜单。
- 点击“亮/暗”开关可切换浅色和暗色模式。
- 点击铃铛图标可查看消息提醒。
- 点击用户名可进入个人中心或退出登录。

## 8. 采购管理

### 8.1 采购订单

菜单路径：

```text
采购管理 -> 采购订单
```

采购订单用于记录向供应商采购商品的业务单据。

常用操作：

1. 点击“新建采购单”。
2. 选择供应商、商品，填写数量和单价。
3. 保存后订单状态为“待审核”。
4. 有审核权限的用户点击“审核”，可选择通过或驳回。
5. 审核通过后，可执行“到货”。
6. 到货后，可选择仓库执行“入库”。
7. 入库完成后，系统自动增加对应商品库存，并记录库存流水。

采购单常见状态：

| 状态 | 含义 |
| --- | --- |
| 待审核 | 新建后等待审核 |
| 已通过 | 审核通过，等待到货或后续处理 |
| 已驳回 | 审核未通过，可修改后重新提交 |
| 已到货 | 商品已到货，等待入库 |
| 已入库 | 商品已入库，库存已增加 |
| 已取消 | 订单已取消 |

### 8.2 采购入库

菜单路径：

```text
采购管理 -> 采购入库
```

用于集中处理已到货但未入库的采购单。

操作步骤：

1. 打开采购入库页面。
2. 查看待入库采购单。
3. 选择入库仓库。
4. 点击入库确认。
5. 系统自动更新库存数量并生成库存流水。

### 8.3 采购分析

菜单路径：

```text
采购管理 -> 采购分析
```

用于查看采购结构、采购金额、供应商占比等统计信息，辅助分析采购业务。

## 9. 销售管理

### 9.1 销售信息发布

菜单路径：

```text
销售管理 -> 销售信息发布
```

用于发布销售公告、促销信息或业务通知。销售相关人员可查看公告内容。

### 9.2 销售订单

菜单路径：

```text
销售管理 -> 销售订单
```

销售订单用于记录客户购买商品的业务单据。

常用操作：

1. 点击“新建销售单”。
2. 选择客户、商品，填写数量和单价。
3. 保存后订单状态为“待审核”。
4. 有审核权限的用户点击“审核”，可选择通过或驳回。
5. 审核通过后，可选择仓库执行“出库”。
6. 出库后系统自动扣减对应商品库存，并生成库存流水。
7. 客户付款后，可在订单中登记“回款”。

销售单常见状态：

| 状态 | 含义 |
| --- | --- |
| 待审核 | 新建后等待审核 |
| 已通过 | 审核通过，等待出库 |
| 已驳回 | 审核未通过，可修改后重新提交 |
| 已出库 | 商品已出库，库存已扣减 |
| 部分回款 | 已登记部分回款 |
| 已回款 | 销售金额已全部回款 |
| 已取消 | 订单已取消 |

### 9.3 销售出库

菜单路径：

```text
销售管理 -> 销售出库
```

用于集中处理审核通过但未出库的销售单。

操作步骤：

1. 打开销售出库页面。
2. 查看待出库销售单。
3. 选择出库仓库。
4. 点击出库确认。
5. 系统校验库存是否充足。
6. 出库成功后，系统扣减库存并记录库存流水。

### 9.4 销售绩效

菜单路径：

```text
销售管理 -> 销售绩效
```

用于查看销售趋势、达成率、区域表现等统计信息。

## 10. 库存管理

### 10.1 库存总览

菜单路径：

```text
库存管理 -> 库存总览
```

用于查看各仓库中商品的当前库存数量、预警阈值和库存状态。

常用操作：

- 按仓库筛选库存。
- 按商品关键字查询。
- 查看库存是否低于预警阈值。

### 10.2 库存流水

菜单路径：

```text
库存管理 -> 库存流水
```

用于查看库存数量变化记录，包括采购入库、销售出库、调拨入库、调拨出库和库存盘点。

### 10.3 库存盘点

菜单路径：

```text
库存管理 -> 库存盘点
```

用于对仓库中的商品进行盘点。

操作步骤：

1. 选择商品。
2. 选择仓库。
3. 填写实际盘点数量。
4. 填写备注。
5. 提交盘点。

提交后系统会按盘点数量修正库存，并生成库存流水记录。

### 10.4 库存追溯台账

菜单路径：

```text
库存管理 -> 库存追溯台账
```

用于按时间线查看库存变化轨迹，便于追踪商品从采购入库到销售出库的流转过程。

## 13. 使用注意事项

1. 登录时必须输入正确验证码，验证码可点击刷新。
2. 不同角色看到的菜单和按钮不同，属于正常权限控制。
3. 采购入库会增加库存，销售出库会减少库存。
4. 销售出库前应确认对应仓库库存充足。
5. 删除或停用基础资料前，应确认该资料没有正在使用的业务单据。
6. 答辩演示环境默认会在后端启动时初始化演示数据，如需保留操作后的数据，请参考部署文档调整数据库初始化配置。
7. 建议使用 Chrome、Edge 或 Firefox 浏览器访问系统。

## 14. 答辩演示建议

答辩时可按以下顺序演示：

1. 使用 `admin / 123456` 登录系统。
2. 展示驾驶舱，说明系统覆盖采购、销售、库存和报表追溯。
3. 展示基础资料，包括商品、供应商、客户和仓库。
4. 新建一张采购单，演示审核、到货、入库。
5. 打开库存总览和库存流水，说明采购入库后库存增加。
6. 新建一张销售单，演示审核、出库、回款。
7. 打开合规追溯，按订单或商品查询业务链路。
8. 展示账号管理和角色权限，说明系统支持权限控制。
